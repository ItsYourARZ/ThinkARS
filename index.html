Anirudh Rajesh is a web developer and student with a growing passion towards AI, data science, and secure system design. He specializes in creating modern, high-performance web experiences that balance aesthetics with functionality. Fluent in Python, Rust, C#, and HTML, Anirudh constantly explores cutting-edge technologies to expand his skill set and push creative boundaries.
